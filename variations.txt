# 바꿔 말하기 원본 (앱의 복습·홈·단어 카드 「바꿔 말하기」 시트가 읽는 파일, 위젯은 안 읽음)
# 형식: V | 원래 일본어 | 종류 | 바뀐 일본어 | 읽는 법 | 뜻
# 원래 일본어: expressions.txt의 문장, 또는 대화 A/B 한 줄을 글자 하나 다르지 않게 그대로
# 종류: 단어(단어 하나 바꾸기) / 다른말(같은 뜻 다른 말) / 공손(더 공손하게) / 반대(반대 뜻)
#       어색한 종류는 빼도 돼요. 한 문장에 같은 종류는 하나만.
# 바뀐 일본어: 바뀐 부분을 [ ]로 감싸요 → 앱에서 빨간색. 읽는 법은 히라가나만 ([ ] 없이)
# 앱은 받을 때마다 이 파일을 통째로 새로 읽어요. 고치면 바로 반영돼요.
